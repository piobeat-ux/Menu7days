# 🥗 Сытая Неделя — 1600 ккал

Интерактивное веб-приложение (PWA) с планом питания на 7 дней.

## 🌟 Особенности

- 📅 **7-дневный план питания** — 1600 ккал/день, 100-120г белка
- 🌐 **6 языков** — русский, английский, испанский, итальянский, французский, немецкий
- 💧 **Трекер воды** — интерактивные стаканчики
- 🛒 **Список покупок** — автоматическая генерация из меню
- 🆘 **SOS-режим** — помощь при срывах и тяге к сладкому
- 📊 **Трекер привычек** — вода, сон, движение, белок
- 🍰 **Бонусные десерты** — 5 рецептов с низким содержанием сахара
- 📱 **PWA** — работает офлайн после первой загрузки

## 🚀 Деплой

### Вариант 1: Vercel (рекомендуется)

1. Установите Vercel CLI:
   ```bash
   npm i -g vercel
   ```

2. В корне проекта выполните:
   ```bash
   vercel
   ```

3. Следуйте инструкциям. После деплоя получите ссылку вида:
   ```
   https://your-project.vercel.app
   ```

### Вариант 2: Netlify

1. Установите Netlify CLI:
   ```bash
   npm i -g netlify-cli
   ```

2. Соберите проект:
   ```bash
   npm run build
   ```

3. Задеплойте:
   ```bash
   netlify deploy --prod --dir=dist
   ```

### Вариант 3: GitHub Pages

1. Создайте репозиторий на GitHub
2. Запушьте код
3. В Settings → Pages выберите ветку `main` и папку `/dist`
4. Получите ссылку: `https://username.github.io/repo-name`

### Вариант 4: Локальный сервер

```bash
npm run build
npm run preview
```

Откройте http://localhost:4173

## 📦 Структура проекта

```
src/
├── components/          # React компоненты
│   ├── Dashboard.tsx    # Главная страница
│   ├── Menu.tsx         # Меню на неделю
│   ├── ShoppingList.tsx # Список покупок
│   ├── SosMode.tsx      # SOS-режим
│   ├── Settings.tsx     # Настройки
│   └── WelcomeScreen.tsx# Экран приветствия
├── data/
│   ├── mealPlan.ts      # Данные о блюдах
│   └── mealPlanI18n.ts  # Переводы контента
├── i18n/
│   ├── translations.ts  # UI переводы
│   └── LanguageContext.tsx # Контекст языка
├── App.tsx              # Главный компонент
├── main.tsx             # Точка входа
└── index.css            # Стили
```

## 📱 PWA

Приложение поддерживает установку на мобильные устройства:
- iOS: Safari → "Добавить на экран"
- Android: Chrome → "Установить приложение"

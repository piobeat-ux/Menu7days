## 🌐 Способы публикации:

### 1. Vercel (рекомендуется) ⭐

**Самый простой способ — 2 минуты:**

```bash
# Установите Vercel CLI
npm install -g vercel

# В папке проекта выполните:
vercel

# Следуйте инструкциям
```

После деплоя получите ссылку вида: `https://sytaja-nedelya.vercel.app`

**Преимущества:**
- Бесплатно
- Автоматический HTTPS
- Быстрый CDN по всему миру
- Автоматические обновления при push в Git

### 2. Netlify

```bash
# Установите Netlify CLI
npm install -g netlify-cli

# Соберите проект
npm run build

# Опубликуйте папку dist
netlify deploy --prod --dir=dist
```

### 3. GitHub Pages

1. Создайте репозиторий на GitHub
2. Запушьте код
3. В Settings → Pages выберите ветку `main` и папку `/dist`
4. Получите ссылку: `https://username.github.io/repo-name`

### 4. Локальный сервер (для тестирования)

```bash
npm run build
npm run preview
```

Откройте: http://localhost:4173

## 📱 Установка как PWA

После публикации пользователи смогут установить приложение:

**iOS (Safari):**
1. Откройте сайт в Safari
2. Нажмите "Поделиться"
3. Выберите "На экран Домашний"

**Android (Chrome):**
1. Откройте сайт в Chrome
2. Нажмите меню (⋮)
3. Выберите "Добавить на главный экран"
